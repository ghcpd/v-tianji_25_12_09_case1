# E-Commerce Dashboard

A modern e-commerce dashboard application with product management, shopping cart, and order processing capabilities.

## Project Structure

```
.
├── version1/          # Application version 1
├── version2/          # Application version 2
└── README.md          # This file
```

## Quick Start

### Version 1

```bash
cd version1
npm install
npm run dev
```

### Version 2

```bash
cd version2
npm install
npm run dev
```

## Features

- Product catalog with search and filtering
- Shopping cart with quantity management
- Checkout form with validation
- Order history page
- Dashboard with analytics charts
- Responsive navigation

## Technology Stack

- React 18.2.0
- React Router DOM 6.20.0
- Vite 5.0.8
- Recharts 2.10.3
